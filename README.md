# Задание
Разработайте Spring Boot приложение с REST API для управления задачами (TODO-лист) и настройте полный CI/CD пайплайн с автоматическим деплоем на виртуальную машину.

TODO-лист (список задач) — это приложение для управления задачами, где можно:

Создавать новые задачи (например: “Купить молоко”)
Просматривать список всех задач
Отмечать задачи как выполненные
Удалять или редактировать существующие задачи
Требования к приложению:

- REST API для CRUD операций с задачами:
- POST /tasks — добавить задачу
- GET /tasks — получить все задачи
- PUT /tasks/{id} — обновить задачу
- DELETE /tasks/{id} — удалить задачу

- Хранение задач в памяти (без БД)
- Валидация входных данных
- Покрытие тестами ≥ 70%
